# Blueprint

This folder is the design for a fuller production version of an OTC desk: real bank and on-chain settlement, a chain watcher, payout approvals, hedging, reconciliation and audit history.

It is a plan and is **not implemented** in this repository. The running demo implements a deliberately smaller slice, defined in [`openspec/changes/demo-slice`](../../openspec/changes/demo-slice/). The blueprint is kept to show what that slice was cut from and how it would grow.
